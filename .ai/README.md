# featcache — AI Agent Development Governance

This directory defines the **approved skills list** and **mandatory workflow** for AI agents (Claude Code, Copilot, etc.) working in this repository.

> Purpose: ensure AI agents use a consistent development workflow, prevent uncontrolled AI changes, and record the required development steps.

## Files

| File | Description |
|------|-------------|
| [skill-lock.json](skill-lock.json) | Approved AI skills and tools list (version-locked) |
| [AGENTS.md](AGENTS.md) | AI agent development workflow (before/during/after coding) |

## Companion documents

- [AI_CONTRIBUTING.md](../AI_CONTRIBUTING.md) — AI contribution rules (disclosure, validation, responsibility)
- [CONTRIBUTING.md](../CONTRIBUTING.md) — general contribution guide
- [CLAUDE.md](../CLAUDE.md) — Claude Code project guidance
